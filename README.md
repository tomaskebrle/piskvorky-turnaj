# Turnajová podstránka — opravený čas

Statická kopie stránky [Turnajová podstránka](https://pisqworky.cz/turnaj-podstranka) na [pisqworky.cz](https://pisqworky.cz), s opraveným hodinami.

Původní hodiny („Aktuální čas“) jsou vložené iframe widget z timeanddate.com a na některých sítích nebo v prohlížečích se nenačtou, případně se po načtení neaktualizují. Tady je nahrazuje malý JavaScript, který ukazuje běžící čas v časovém pásmu Europe/Prague ve stejném formátu `HH:MM:SS`.

Vzhled, styly a obrázky jsou z originální stránky. Navigační odkazy vedou zpět na pisqworky.cz.

Živá stránka: https://tomaskebrle.github.io/piskvorky-turnaj/
